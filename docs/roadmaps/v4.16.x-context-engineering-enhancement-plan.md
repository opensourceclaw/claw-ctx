[EN] ## 🎯 阶段一：高优先级 (P1) — v4.16.0

[EN] 目标：解决 Self-Refinement  and  Prompt 策略控制（小版本增量）

### 1.1 Self-Refinement 机制

[EN] **现状**: dreaming pipeline 仅做记忆提升，无输出质量反馈

[EN] **目标**:  at  afterTurn 阶段增加输出质量评估 with 改进循环

**实现方案**:

```
当前流程:
  Turn → Assemble → Generate → AfterTurn → (end)

增强流程:
  Turn → Assemble → Generate → Self-Evaluate → 
    [如果 not 满意] → Refine → Re-Evaluate → 
[EN] [满意 or 达 to 重试 up 限] → AfterTurn → (end)
```

**模块设计**:

```typescript
// src/self_refiner.ts (NEW)

export interface SelfRefinerConfig {
  /** 最 large 重试次数 */
  maxRetries: number;
  /** 评估阈值 (0-1) */
  qualityThreshold: number;
  /** 触发条件 */
  triggerOn: ("low-confidence" | "error-detected" | "always")[];
}

export interface SelfRefinementResult {
  originalOutput: string;
  refinedOutput: string;
  evaluationScore: number;
  loops: number;
  accepted: boolean;
}

export class SelfRefiner {
  async evaluate(output: string, context: Message[]): Promise<EvaluationResult>;
  async refine(output: string, feedback: string, context: Message[]): Promise<string>;
  async run(input: string, context: Message[], config: SelfRefinerConfig): Promise<SelfRefinementResult>;
}
```

**关键技术点**:
[EN] 1. **输出评估**: 使用置信度 + 一致性检测
[EN] 2. **反思生成**: 提取失败原因，生成改进指引
[EN] 3. **收敛检测**: 防止无限循环

**时间预估**: 2 周

### 1.2 Prompt 策略控制器

**现状**: 无 CoT/ToT/GoT 支持

[EN] **目标**: 支持动态推理策略选择

**实现方案**:

```typescript
// src/prompt_strategy_controller.ts (NEW)

export type ReasoningStrategy = 
  | "direct"           // 直接回答
  | "chain-of-thought" // 链式推理
  | "tree-of-thoughts" // 树状搜索
  | "graph-of-thoughts" // 图状推理
  | "self-consistency" // 自一致性;

export interface PromptStrategyConfig {
  /** 默认策略 */
  defaultStrategy: ReasoningStrategy;
[EN] /** 任务类型 → 策略映射 */
  taskStrategyMap: Record<string, ReasoningStrategy>;
[EN] /** 复杂度阈值，超过则升级策略 */
  complexityThreshold: {
    chain-of-thought: number;  // token 数
    tree-of-thoughts: number;
    graph-of-thoughts: number;
  };
  /**  is 否启用 self-consistency */
  selfConsistency: boolean;
  /** self-consistency 采样数 */
  selfConsistencySamples: number;
}

export class PromptStrategyController {
  selectStrategy(task: Task, context: Message[]): ReasoningStrategy;
  applyStrategy(prompt: string, strategy: ReasoningStrategy, options?: StrategyOptions): string;
  detectComplexity(text: string): number;
}
```

** with  OpenClaw 协作**:
[EN] - 通过 systemPromptAddition 注入策略指令
-  with  claw-mem  of  importance 评估联动

**时间预估**: 2 周

[EN] ## 🎯 阶段二： in 优先级 (P2) — v4.17.0

[EN] 目标：增强 Long Sequence 处理 and  Structured Context 支持

### 2.1 Long Sequence 优化

[EN] **现状**: 仅 token 计数，无位置优化

[EN] **目标**: 缓解 "lost-in-the-middle" 现象

**实现方案**:

```typescript
// src/position_optimizer.ts (NEW)

export interface PositionOptimizerConfig {
[EN] /** 重要信息位置偏好 */
  positionPreference: "head" | "tail" | "balanced" | "adaptive";
[EN] /** 关键信息重复次数 */
  keyInfoRepetitions: number;
  /** 分块 large 小 */
  chunkSize: number;
[EN] /** 滑动窗口步长 */
  windowStep: number;
}

export class PositionOptimizer {
  /**
[EN] * 核心优化策略:
[EN] * 1. 识别关键信息（通过 importance scoring）
[EN] * 2. 分散放置关键信息（头尾+ in 间）
[EN] * 3.  to 超长 up  down 文使用滑动窗口
   */
  optimize(messages: Message[], config: PositionOptimizerConfig): Message[];
  
  /**
[EN] * 关键信息提取
   */
  extractKeyInfo(messages: Message[]): KeyInfo[];
  
  /**
[EN] * 滑动窗口压缩
   */
  slidingWindowCompress(messages: Message[], budget: number): Message[];
}
```

**Lost-in-the-Middle 缓解策略**:

[EN] | 策略 | 描述 | 效果 |
|------|------|------|
[EN] | **重复注入** | 关键信息 at 头部 and 尾部重复 | +15% 召回 |
[EN] | **位置编码增强** | 增加显式位置标记 | +8% |
[EN] | **分层展示** | 使用摘要+详情结构 | +12% |
[EN] | **重要性排序** | 高重要性信息前置 | +20% |

**时间预估**: 2 周

### 2.2 Structured Context 增强

[EN] **现状**: graph 初步支持，无 Table/DB 线性化

[EN] **目标**: 增强结构化数据处理 can 力

**实现方案**:

```typescript
// src/structured_context_handler.ts (NEW)

export type StructuredDataType = "table" | "json" | "sql-result" | "csv" | "kg";

export interface StructuredDataConfig {
  /** 支持 of 类型 */
  supportedTypes: StructuredDataType[];  
  /** 最 large 行数 */
  maxRows: number;
  /** 压缩策略 */
  compressionStrategy: "truncate" | "summarize" | "sample" | "schema-only";
  /**  is 否保留关系 */
  preserveRelations: boolean;
}

export class StructuredContextHandler {
  /**
[EN] * 检测输入 is 否 for 结构化数据
   */
  detect(data: string): StructuredDataType | null;
  
  /**
[EN] * 转换 for  LLM  can 处理 of 文本
   */
  verbalize(data: string, type: StructuredDataType, config: StructuredDataConfig): string;
  
  /**
[EN] * 提取关系用于图增强
   */
  extractRelations(data: string, type: StructuredDataType): Relation[];
  
  /**
   * Table 转 Markdown/CSV
   */
  tableToMarkdown(table: any[]): string;
  
  /**
[EN] * JSON 转自然语言摘要
   */
  jsonToSummary(json: object): string;
  
  /**
   * SQL 结果摘要
   */
  sqlResultSummarize(result: QueryResult, maxRows: number): string;
}
```

**时间预估**: 1 周

[EN] ## 🎯 阶段三：低优先级 (P3) — v4.18.0

[EN] 目标：Multimodal 支持（长期规划）

### 3.1 Multimodal Context 处理

**现状**: 无支持

[EN] **目标**: 支持图像/音频 up  down 文

**架构设计**:

```typescript
// src/multimodal_context_handler.ts (NEW)

export type ModalType = "text" | "image" | "audio" | "video";

export interface MultimodalConfig {
  /** 支持 of 模态 */
  supportedModalities: ModalType[];
[EN] /** 文本描述最 large 长度 */
  maxDescriptionLength: number;
[EN] /**  is 否启用视觉定位 */
  enableGroundTruthing: boolean;
  /** 图像 token 压缩比 */
  imageCompressionRatio: number;
}

export class MultimodalContextHandler {
  /**
[EN] * 检测并提取多模态内容
   */
  extractMultimodalContent(message: Message): MultimodalContent[];
  
  /**
[EN] * 生成图像描述
   */
  describeImage(image: Buffer): Promise<string>;
  
  /**
[EN] * 生成音频转录
   */
  transcribeAudio(audio: Buffer): Promise<string>;
  
  /**
   * 压缩视觉 token
   */
  compressVisualTokens(tokens: number[], ratio: number): number[];
  
  /**
[EN] * 多模态 to 文本 of 转换
   */
  modalityToText(content: MultimodalContent): string;
}
```

**技术难点**:
[EN] 1. 图像 token 数量巨 large （需视觉压缩）
[EN] 2. 跨模态注意力
3. 定位 with grounding

[EN] **时间预估**: 4 周（需要依赖视觉模型）
