## 1. Recuris 核心架构(一段话版)

长程任务中「历史增长淹没任务状态、skill 调用错位」→ **EM–WM 耦合**:Working Memory 维护紧凑且**经验证的**任务状态(checker 把环境反馈转成结构化状态更新,不信任对话原文),状态驱动 Experiential Memory 的 skill 检索;执行轨迹因此成为结构化证据,失败可归因到四组件(E=skill / W=状态 / ρ=调用时机 / C=转移判定,定位准确率 64.8% vs 仅凭结果 13.0%);固定 Meta-Agent 做组件级 scoped patch,过验证门(修复目标失败且不退化含 anchor 任务的 held-out 集)才准入。**递归有界**:递归仅在记忆控制层,底座模型与 Meta-Agent 全程冻结。

结果:37 模型×基准 35 升;优势随交互长度增长(最长任务 +32.2 分);六类长程失败降 20–86%;进化产物跨任务/跨模型迁移。

## 2. 对 claw-mem 的迭代启示(按优先级)

### T-A 组件化记忆卡 + 组件归因字段(高)

**证据**:组件归因定位准确率 64.8% vs 任务结果 13.0%(5 倍);scoped patch 优于全量重写。

**方案**:错误模式卡(已入阵,见 precision-feedback 文档增补)升级为**四组件归因体系**——每张卡标注故障归属组件类别。映射到 claw-mem 语境:
- **skill 缺陷**(E)= 程序记忆卡本身错误/缺失 → 修卡
- **状态缺陷**(W)= 任务状态维护遗漏 → 修状态 schema
- **调用时机**(ρ)= 检索/触发条件不当 → 修注入触发规则
- **转移判定**(C)= 完成判定/验证谓词错误 → 修验证标准

记忆卡效果度量(已规划 T3)按组件维度统计——哪类组件的卡避错率最低,就是下一轮修复重点。

### T-B 验证门 + anchor 回归判据(高)

**证据**:§3.4.4 门控更新保留既有能力;开发集含 anchor 任务防遗忘。

**方案**:记忆卡的准入/更新沿用家族既有 gate 哲学:新卡必须修复目标失败场景(正向)且在 anchor 场景(历史上已正确处理的任务样本集)上不引入回归(反向)。与 claw-rsi 的提案-验证通道对齐,记忆层不自持写入。

### T-C 结构化状态更新经 checker(中)

**证据**:环境反馈→结构化状态更新(checker),不信对话原文;幻觉完成类失败 -86%。

**方案**:claw-mem 的经验写入路径增「验证过滤器」——从对话/轨迹提炼的记忆条目须经结构化校验(字段完整性/与已知事实一致性/来源可溯),不合格不入库。与 claw-graph 的 governed write 哲学同源:记忆也是「受治理写入」而非自由写入。

## 3. 对 claw-ctx 的迭代启示(按优先级)

### T-D 任务状态驱动的检索(高)

**证据**:对完整历史检索 vs 对 WM 状态检索,后者 skill 调用更准更省(§3.3.4);「中心局限不是缺经验,而是缺紧凑可靠的任务状态」。

**方案**:ctx_inject / skill 注入的检索键从「原始查询/全文历史」升级为「**结构化任务状态**」(当前进度/未解决目标/已排除方案)。claw-ctx 可定义轻量 state 字段约定(与 claw-graph task 节点 attrs 兼容),注入时以状态为锚——解决「初始指令已过时、历史混杂噪声」的经典失败模式。

### T-E 压缩保结构摘要(呼应既有规划,补充证据)

**证据**:WM 之所以有效,是它持续维护「未解决目标」的显式表示;compaction 后探索激增(SWE-Milestone Fig 13)正因结构理解丢失。

**方案**:compaction-digest 规划文档(swe-milestone-evidence-input-compaction-digest.md)的 T1 证据强度升级——Recuris 从正面证明「紧凑可靠的任务状态」是长程执行的第一性需求,compaction 时保 WM 等价物(未解决目标/已确认依赖)应有最高保留优先级。

## 4. 诚实边界

- Recuris 的四组件归因是为「skill memory 记忆控制层」设计的;直接搬到 devclaw 多 agent 流程需映射(已给对照),不是即插即用
- benchmark 以 τ²/SkillFlow 类工具对话任务为主,企业级异构任务未覆盖;「定位准确率 64.8%」也意味着 1/3 误诊——门控兜底是必要的,不是可选
- 部分对比数字基于 2026-08 模型代际
