# Detailed Design: claw-ctx v4.24.0 Self-Refinement Module

**Author**: Jarvis
**Date**: 2026-06-16
**Version**: 4.24.0
**Feature**: Quality evaluation + reasoning strategies

---

## 1. Background

### Current Implementation (v4.23.0)

- **SelfRefiner** (`src/self_refiner.ts`): evaluate() with 5 heuristic checks, refine() rule-based text fixes, run() iterative eval→refine loop with convergence detection
- **PromptStrategyController** (`src/prompt_strategy_controller.ts`): 5 strategy prompt templates (direct/CoT/ToT/GoT/self-consistency), task type detection (12 types), complexity estimation

### Limitations

- Quality evaluation hardcoded in SelfRefiner — not reusable outside afterTurn
- Strategy prompts are static strings in a Record — not extensible, no interface contract
- No dimension-level granularity in evaluation results (only overall score)
- No way for third-party code (e.g., dreaming pipeline) to access quality evaluation independently

### Target

- Extracted `QualityEvaluator` with 4 configurable dimensions (completeness/accuracy/consistency/readability)
- `ReasoningStrategy` interface with CoT/ToT/GoT implementations
- Backward compatible refactoring — all existing APIs unchanged

## 2. Architecture

### Module Layout

```
src/self-refinement/
├── types.ts                           # QualityDimensionResult, QualityEvaluationResult, QualityEvaluatorConfig
├── quality-evaluator.ts               # QualityEvaluator — 4-dimensional evaluation
├── reasoning-strategies/
│   ├── base.ts                        # ReasoningStrategy interface
│   ├── chain-of-thought.ts            # CoT — step-by-step reasoning
│   ├── tree-of-thoughts.ts            # ToT — multi-path exploration
│   ├── graph-of-thoughts.ts           # GoT — network-based reasoning
│   └── mod.ts                         # Barrel exports
└── mod.ts                             # Module barrel exports
```

### Data Flow

```
afterTurn()
  └─ SelfRefiner.evaluate(output)
       └─ QualityEvaluator.evaluate(output)
            ├─ _evalCompleteness()  → score + issues
            ├─ _evalAccuracy()      → score + issues
            ├─ _evalConsistency()   → score + issues
            └─ _evalReadability()   → score + issues
            └─ weighted average    → overallScore

assemble()
  └─ PromptStrategyController.applyStrategy(prompt, strategy)
       └─ ChainOfThoughtStrategy.apply()
       │  └─ TreeOfThoughtsStrategy.apply()
       │  └─ GraphOfThoughtsStrategy.apply()
       └─ result: augmented prompt string
```

### Delegation Pattern

Both SelfRefiner and PromptStrategyController are refactored to delegate to the new module internally while preserving their public APIs:

| Consumer | Delegates to | Backward Compat |
|----------|-------------|-----------------|
| `SelfRefiner.evaluate()` | `QualityEvaluator.evaluate()` | Yes — same params, same return shape |
| `SelfRefiner.refine()` | (unchanged) | Yes |
| `SelfRefiner.run()` | (unchanged) | Yes |
| `PromptStrategyController.applyStrategy()` | `ChainOfThoughtStrategy.apply()` etc. | Yes — same params, same return |
| `PromptStrategyController.getSystemPromptAddition()` | `CoT/ToT/GoT.getSystemPromptAddition()` | Yes |

## 3. Quality Evaluation Dimensions

### 3.1 Completeness (weight: 0.25)

| Check | Detection | Penalty |
|-------|-----------|---------|
| Empty output | `!output?.trim()` | score = 0 |
| Incomplete markers | `TODO`, `FIXME`, `WIP`, `...`, `to be continued` | -0.20 |
| Too short | length < 20 chars | -0.30 |
| Truncation | No sentence-ending punctuation, trailing pipe, unclosed backtick | -0.15 |
| Unclosed CJK brackets | `【`, `「`, `（` without closing pair | -0.15 |

### 3.2 Accuracy (weight: 0.30)

| Check | Detection | Penalty |
|-------|-----------|---------|
| Error language | `error`, `failed`, `exception`, `crash` | -0.15 |
| Undefined/null | `undefined`, `null` (not nullable) | -0.10 |
| Missing resources | `not found`, `does not exist` | -0.10 |
| Low confidence | ≥3 occurrences of `I think`, `perhaps`, `maybe`, `not sure`... | -0.08 each (max -0.30) |

### 3.3 Consistency (weight: 0.25)

| Check | Detection | Penalty |
|-------|-----------|---------|
| Self-contradiction | `but ... not`, `however ... not` | -0.15 |
| Stance reversal | `on the one hand ... on the other hand` | -0.10 |
| Pronoun inconsistency | Mixed `we`/`I` usage | -0.05 |

### 3.4 Readability (weight: 0.20)

| Check | Detection | Penalty |
|-------|-----------|---------|
| Excessively long | length > 50000 | -0.10 |
| Word repetition | single word > 15% of total | -0.10 |
| No paragraph structure | >1000 chars without `\n\n` | -0.10 |
| Unclosed code fence | odd count of ``` | -0.08 |

### 3.5 Score Calculation

```
overallScore = sum(score_i * weight_i) for all 4 dimensions
             / sum(weight_i)
passed = overallScore >= qualityThreshold (default 0.7)
```

## 4. Reasoning Strategy Interface

### Interface

```typescript
interface ReasoningStrategy {
  readonly name: string;
  apply(prompt: string, options?): string;
  getSystemPromptAddition(): string;
}
```

### Implementations

| Strategy | Prompt Template |
|----------|----------------|
| CoT | "Let's think step by step..." |
| ToT | "Explore multiple solution paths..." |
| GoT | "Build a network of ideas..." |

### Backward Compatibility

The existing `ReasoningStrategy` string union type (`"direct" | "chain-of-thought" | "tree-of-thoughts" | "graph-of-thoughts" | "self-consistency"`) is preserved in `prompt_strategy_controller.ts`. The new interface is exported as `ReasoningStrategyInterface` from `index.ts` to avoid name collision.

## 8. Risks & Mitigation

| Risk | Mitigation |
|------|-----------|
| Double maintenance if SelfRefiner adds eval logic outside QualityEvaluator | `evaluate()` fully delegates — no parallel logic |
| Strategy template drift between old static map and new strategy classes | Templates are exact copies, verified by integration tests |
| Performance: QualityEvaluator creates many RegExp objects | All patterns are module-level constants (compiled once) |
