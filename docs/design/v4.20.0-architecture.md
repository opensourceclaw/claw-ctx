## 1. Design Overview

v4.20.0 聚焦三个能力，均建立在现有架构之上：

```
Gateway (OpenClaw)
    │
    ├── assemble() ─── claw-ctx ─── claw-mem (记忆检索)
    ├── compact()  ─── claw-ctx ─── Session JSONL (压缩)
    ├── maintain() ─── claw-ctx ─── Decay Engine
    │
    ▼ NEW in v4.20.0
    ├── auto-compact trigger (drift ≥ 0.7)
    ├── auto-new-session signal (drift ≥ 0.9)
    └── cross-session memory pipeline (RelevanceScorer)
```

## 2. P0: Gateway 深度集成

### 2.1 当前状态

claw-ctx 已通过 `openclaw.plugin.json` 注册为 context-engine 插件。Gateway 在 `plugins.slots.contextEngine = "claw-ctx"` 时调用其方法。

### 2.2 设计方案

**不新增代码**，改为配置验证 + 集成测试：

- 在 openclaw.json 中确认 `plugins.slots.contextEngine = "claw-ctx"`
- 验证 assemble/ingest/maintain 在实际对话中生效（日志验证）
- 与现有 Hook 机制共存测试：确保 claw-ctx 的 context injection 不与 dist hook 冲突

### 2.3 验收

- Gateway 日志确认 claw-ctx 方法被调用
- Hook 注入 + claw-ctx 注入 同时存在不冲突

## 3. P1: Drift 自动化响应

### 3.1 新增模块

```
src/auto-compact.ts    — AutoCompactController
src/auto-session.ts    — AutoSessionController
```

### 3.2 AutoCompactController

```typescript
interface AutoCompactConfig {
  driftThreshold: number;     // default: 0.7
  cooldownMs: number;         // default: 300000 (5 min)
  maxCompactsPerSession: number; // default: 3
}

class AutoCompactController {
  shouldCompact(driftScore: number): boolean;
  lastCompactAt: number | null;
  compactCount: number;
}
```

在 `assemble()` 返回中新增 `autoCompact: boolean` 字段，Gateway 检查此字段决定是否触发 compact。

### 3.3 AutoSessionController

```typescript
interface AutoSessionConfig {
  driftThreshold: number;     // default: 0.9
  suggestionCooldownMs: number; // default: 600000 (10 min)
}

class AutoSessionController {
  shouldSuggestNewSession(driftScore: number): boolean;
  generateSuggestion(): string; // 返回建议文本
}
```

在 `assemble()` 返回中新增 `newSessionSuggested: boolean` 和 `newSessionReason: string`。

### 3.4 engine.ts 变更

在 `assemble()` 末尾添加：

```typescript
const driftScore = this._driftDetector.getDriftScore();
const autoCompact = this._autoCompact.shouldCompact(driftScore);
const newSessionSuggested = this._autoSession.shouldSuggestNewSession(driftScore);

return {
  ...result,
  driftScore,
  autoCompact,
  newSessionSuggested: newSessionSuggested ? this._autoSession.generateSuggestion() : null,
};
```

### 3.5 配置项

在 openclaw.json 中新增：

```json
{
  "plugins": {
    "entries": {
      "claw-ctx": {
        "config": {
          "autoCompact": { "driftThreshold": 0.7, "cooldownMs": 300000 },
          "autoSession": { "driftThreshold": 0.9, "suggestionCooldownMs": 600000 }
        }
      }
    }
  }
}
```

## 4. P2: Cross-session 记忆复用

### 4.1 新增模块

```
src/relevance-scorer.ts — RelevanceScorer
```

### 4.2 RelevanceScorer

```typescript
class RelevanceScorer {
  score(memory: MemoryRecord, currentContext: {
    entities: string[];
    topics: string[];
    recentMessages: string[];
  }): number;
  // 评分维度:
  // - entity overlap (40%): 共享实体数量
  // - topic similarity (35%): 话题余弦相似度
  // - recency (15%): 时间衰减
  // - confidence (10%): 记忆置信度
}
```

### 4.3 SessionStateExtractor 增强

新增 `extractCrossSession()`:

```typescript
extractCrossSession(
  query: string,
  options?: { maxSessions?: number; minRelevance?: number }
): CrossSessionContext[];
```

调用 claw-mem 搜索历史 session_summary 标签 → RelevanceScorer 过滤 → 返回高相关上下文。

### 4.4 engine.ts 变更

在 `_loadPreviousSessionContext()` 中集成 RelevanceScorer，替换当前的简单 tag 搜索。

## 6. 性能目标

| 指标 | 目标 |
|------|------|
| autoCompact 判断延迟 | < 1ms (纯计算) |
| autoSession 判断延迟 | < 1ms |
| RelevanceScorer.score() | < 5ms per record |
| Cross-session 加载 | < 200ms |
| assemble() 总延迟增量 | < 50ms |

## 7. 风险

| 风险 | 缓解 |
|------|------|
| autoCompact 误触发 | cooldown + maxCompactsPerSession 限制 |
| Cross-session 数据量过大 | RelevanceScorer 过滤 + maxSessions 限制 |
| Gateway 不支持 autoCompact 字段 | 向后兼容，Gateway 忽略未知字段 |
