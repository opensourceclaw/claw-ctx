## 目标

把 claw-ctx 从「API-only（0 工具）」升级为「可被 OpenClaw 直接调用的 3 工具插件」。注册 `ctx_compact`、`ctx_build`、`ctx_inject` 三个工具。

## 现状与差距

claw-ctx 已有完整的 `ContextCapability`（`src/capability/`，v6.0.0），方法：`bootstrap` / `ingest` / `assemble` / `compact` / `closeSession` / `healthCheck`。

但 `openclaw_plugin/index.ts` 的 `register(api)` 只做了空壳 `api.registerPlugin()`，无 `api.registerTool()`；`openclaw.plugin.json` 也无 `contracts.tools`。故 0 工具。

> 参考实现（同生态已验证）：
> - `claw-rl/claw_rl_plugin/index.ts` — 纯 TS `api.registerTool(factory, {names:[...]})`
> - `claw-mem/src/plugin.ts` — 多工具注册完整样例

## 工具注册规范

```typescript
interface OpenClawPluginApi {
  registerTool(
    factory: (ctx: any) => {
      name: string;
      label?: string;
      description: string;
      parameters: { type: 'object'; properties: Record<string, any>; required?: string[] };
      execute: (toolCallId: string, params: any) => Promise<any>;
    },
    opts?: { names: string[] },
  ): void;
}
```

`openclaw.plugin.json` 加：
```json
"contracts": { "tools": ["ctx_compact", "ctx_build", "ctx_inject"] }
```

## 三个工具设计

### 1. ctx_compact — 手动触发上下文精简

映射 `ContextCapability.compact(CompactParams)`。

parameters:
- sessionId (string, required)
- strategy (string, enum aggressive/balanced/conservative, default balanced)
- threshold (number, 缺省取 config.compactThreshold)
- force (boolean, default false)

返回：`{ ok, compacted, reason, originalTokens, compressedTokens, duration }`

### 2. ctx_build — 按配置组装上下文

映射 `ContextCapability.assemble(AssembleParams)`。

parameters:
- sessionId (string, required)
- sources (array<string>, 预留)
- filters (object, 预留)
- budget (number, token 预算)
- model (string, 目标模型)

返回：`{ estimatedTokens, messages 数量, confidenceReport?, autoCompact? }`（不回传完整 messages）

### 3. ctx_inject — 定向上下文注入（需新增能力方法）

`ContextCapability` 新增 `inject(params: InjectParams): Promise<InjectResult>`：

```typescript
interface InjectParams { targetSessionId: string; content: string; position?: "prepend"|"append"|"replace"; }
interface InjectResult { injected: boolean; reason?: string; }
```

parameters:
- targetSessionId (string, required)
- content (string, required)
- position (string, enum prepend/append/replace, default append)

> `replace` 若无底层语义则降级 append 并在 reason 说明。

## 权限映射

OpenClaw 权限由 gateway 统一管理；插件侧 `contracts.tools` 声明工具清单，roles 映射交 gateway，不在插件硬编码。
