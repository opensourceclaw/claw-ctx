# claw-ctx v5.9.1 概要设计 — 版本号动态化

**版本**: v5.9.1
**日期**: 2026-07-06
**状态**: 设计中
**作者**: Friday (A)

---

## 1. 问题定义

### 1.1 现状

`src/index.ts` 中两处硬编码版本号：

```typescript
version: "5.9.0",                           // 行 62
api.logger.info("[claw-ctx] v5.9.0 registered");  // 行 74
```

每次版本升级需要手动修改这两处，v5.9.0 升级时 Jarvis 遗漏了导致运行时仍显示 5.6.0。

### 1.2 目标

版本号从 `package.json` 单一来源读取，构建时自动注入，无需手动同步。

---

## 2. 设计方案

### 2.1 方案：构建时生成 `src/version.ts`

```
package.json (version: "5.9.1")
       │
       │ build script reads
       ▼
src/version.ts (自动生成, .gitignore)
       │
       │ import { VERSION } from "./version.js"
       ▼
src/index.ts (plugin.version + log message)
```

### 2.2 实现步骤

**Step 1**: 新增构建辅助脚本 `scripts/gen-version.mjs`

```javascript
import { readFileSync, writeFileSync } from "node:fs";
import { resolve, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = dirname(fileURLToPath(import.meta.url));
const pkg = JSON.parse(readFileSync(resolve(__dirname, "../package.json"), "utf-8"));
const version = pkg.version;

writeFileSync(
  resolve(__dirname, "../src/version.ts"),
  `// Auto-generated by scripts/gen-version.mjs — DO NOT EDIT\nexport const VERSION = "${version}";\n`
);

console.log(`Generated src/version.ts with version ${version}`);
```

**Step 2**: 修改 `package.json` build 脚本

```json
"build": "node scripts/gen-version.mjs && tsc && cp openclaw.plugin.json dist/"
```

**Step 3**: 修改 `src/index.ts`

```typescript
import { VERSION } from "./version.js";

const plugin = {
  // ...
  version: VERSION,
  register(api: any) {
    // ...
    api.logger.info(`[claw-ctx] v${VERSION} registered`);
  },
};
```

**Step 4**: 将 `src/version.ts` 加入 `.gitignore`

```
src/version.ts
```

### 2.3 设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 生成文件 vs import JSON | 生成 .ts 文件 | `package.json` 不在 `rootDir` 内，import 需要改 tsconfig |
| 生成时机 | 构建前（pre-build） | 每次 build 自动同步，零手动操作 |
| 文件位置 | `src/version.ts` | 在 rootDir 内，TypeScript 可直接编译 |
| .gitignore | 是 | 自动生成的文件不应提交 |
