## 背景

### 问题描述

claw-ctx 需要支持 Context Budget 管理，根据任务类型动态调整上下文窗口限制。

### 研究支持

论文 "Context Is What You Need" (arXiv:2509.21361v2) 证明：
- 不同任务类型有不同的 MECW (Maximum Effective Context Window)
- 简单任务（查找）：MECW ~10K tokens
- 复杂任务（推理）：MECW ~2K tokens
- 上下文大小是影响模型准确率的最重要因素

## 开发范围

### 1. Context Budget 系统

**新建文件**: `src/context/ContextBudgetManager.ts`

**核心功能**:
- 定义 `TaskType` 枚举
- 定义 `ContextBudget` 接口
- 实现 `ContextBudgetManager` 类
- 提供 `getBudget()`, `setCustomBudget()`, `checkBudgetUsage()` 方法

**关键常量** (基于论文):
```typescript
TaskType.SIMPLE_LOOKUP: maxTokens = 10000
TaskType.MULTI_LOOKUP: maxTokens = 5000
TaskType.SUMMARIZATION: maxTokens = 3000
TaskType.COMPLEX_REASONING: maxTokens = 2000
```

### 2. Task Type Detection

**新建文件**: `src/detection/TaskTypeDetector.ts`

**核心功能**:
- 实现基于关键词的任务类型检测
- 提供 `detectTaskType(query: string)` 方法
- 提供 `detectFromHistory(messages: Message[])` 方法

**关键词映射**:
```typescript
SIMPLE_LOOKUP: ['find', 'search', 'get', 'retrieve', 'lookup']
MULTI_LOOKUP: ['list all', 'find all', 'count all', 'sum all']
SUMMARIZATION: ['summarize', 'overview', 'summary', 'brief']
COMPLEX_REASONING: ['analyze', 'compare', 'sort', 'rank', 'prioritize']
```

### 3. 配置支持

**新建文件**: `src/config/ContextBudgetConfig.ts`

**配置项**:
```typescript
export interface ContextBudgetConfig {
  enabled: boolean;
  taskTypes: Record<TaskType, ContextBudget>;

    method: 'keyword' | 'ml' | 'hybrid';
    fallbackTaskType: TaskType;
  };
}
```
