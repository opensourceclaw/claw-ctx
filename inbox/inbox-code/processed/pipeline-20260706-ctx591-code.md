## Scope

### 1. 新增 `scripts/gen-version.mjs`

构建辅助脚本，从 `package.json` 读取版本号，生成 `src/version.ts`。

```javascript
import { readFileSync, writeFileSync } from "node:fs";
import { resolve, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = dirname(fileURLToPath(import.meta.url));
const pkg = JSON.parse(readFileSync(resolve(__dirname, "../package.json"), "utf-8"));
const version = pkg.version;

writeFileSync(
  resolve(__dirname, "../src/version.ts"),
  `// Auto-generated by scripts/gen-version.mjs — DO NOT EDIT\nexport const VERSION = "${version}";\n`
);

console.log(`Generated src/version.ts with version ${version}`);
```

### 2. 修改 `package.json` build 脚本

```json
"build": "node scripts/gen-version.mjs && tsc && cp openclaw.plugin.json dist/"
```

### 3. 修改 `src/index.ts`

- 顶部添加 `import { VERSION } from "./version.js";`
- `version: "5.9.0"` → `version: VERSION`
- `[claw-ctx] v5.9.0 registered` → `` `[claw-ctx] v${VERSION} registered` ``

### 4. 添加 `.gitignore` 条目

```
src/version.ts
```

### 5. 版本更新

- `package.json`: `5.9.0` → `5.9.1`
- `openclaw.plugin.json`: `5.9.0` → `5.9.1`
- `src/index.ts` 顶部注释版本号: `5.1.0` → `5.9.1`
