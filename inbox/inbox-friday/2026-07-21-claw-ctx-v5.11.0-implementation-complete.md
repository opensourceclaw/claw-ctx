## Completed

### Phase 1: Core Fixes

#### 1.1 LRUCache (`src/lru-cache.ts`, 新增)

- `get/set/delete/has/clear/prune/entries/size`
- `maxSize` 强制 LRU 淘汰（基于 Map 插入序）
- 可选 `ttlMs` TTL 过期

- 17 个单元测试（`tests/lru-cache.test.ts`）

#### 1.2 L1/L6 内存泄漏修复 (`src/engine.ts`)

替换三个 session-level 缓存：

| 缓存 | 旧实现 | 新实现 |
|------|--------|--------|
| `_memorySearchCache` | `Map` 无界（**泄漏**） | `LRUCache(maxSize=32, ttlMs=30s)` |
| `_rlGovernanceCache` | `Map` + 手动 LRU（~15 行） | `LRUCache(maxSize=10)` |
| `_crossDomainCache` | `Map` + 手动 LRU（~15 行） | `LRUCache(maxSize=10)` |

新增 `engine.closeSession(sessionId)`：主动释放 session 资源，供 OpenClaw 在 session 结束时调用。

### Phase 2: 配置化 + 性能

#### 2.1 SemanticCompressorConfig

```typescript
interface SemanticCompressorConfig {
  minKeep?: number;              // default 20
  duplicateWindowSize?: number;  // default 10
  duplicateThreshold?: number;  // default 0.7
}
```

构造函数接收可选 config，默认行为不变（向后兼容）。

#### 2.2 L4 Jaccard 性能优化

旧实现：每条消息对前 10 条做完整 Jaccard，每条 O(n) Set 构建，整体 O(n×k) 重复分词。

新实现：

- 新增 `tokenize(text): Set<string>` - 一次分词
- 新增 `jaccardSetSimilarity(a: Set, b: Set)` - 直接对 Set 操作
- 滑动窗口 `Map<number, Set<string>>` 复用前序分词结果
- 窗口外条目主动 evict，保持 Map 有界

---

### Phase 2.5: 摘要模板精简

旧格式（4 行 ~80 tokens）：

```
[Compacted History - N earlier messages summarized]
Topics: ...

Continue with the current task using the remaining recent context below.
```

新格式（单行 ~25 tokens）：

```
[Compacted History - N msgs] | Topics: ... | decisions: "..." | entities: ...
```

- 空字段（decisions/entities）省略
- decisions 上限 5 条，entities 上限 8 条
- 保留 `Compacted History` 和 `Topics:` 关键字（现有测试兼容）
- Token 减少约 55%
