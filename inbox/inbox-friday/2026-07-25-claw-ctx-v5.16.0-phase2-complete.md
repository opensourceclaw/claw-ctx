### 3. engine.ts 集成 ✅

**集成点**:
- 构造函数: 初始化 `_modelOptimizer` 实例
- `assemble()`: 检测 model 参数，获取优化提示
- 新增公共 API:
  - `getModelOptimizer()` - 获取优化器实例
  - `getLastOptimizationHint()` - 获取最后一次优化提示
  - `getModelBudgetAllocation()` - 获取模型感知预算分配

**使用示例**:
```typescript
// 在 assemble() 中使用
const result = await engine.assemble({
  sessionId: 'xxx',
  messages: [...],
  model: 'deepseek-v3',  // 模型参数
});

// 获取优化提示
const hint = engine.getLastOptimizationHint();
// hint.strategy = 'static-prefix'
// hint.cacheStaticPrefix = true
// hint.compressionThreshold = 100000
```

## 架构说明

```
model-profile.ts           ← 模型特性定义 (35个模型)
       ↓
model-aware-optimizer.ts   ← 策略选择 + 预算计算
       ↓
engine.ts                  ← assemble() 中使用优化提示
```

**策略选择逻辑**:
1. `assemble(model='deepseek-v3')` → 调用 `_modelOptimizer.getOptimizationHint()`
2. 返回 `{ strategy: 'static-prefix', cacheStaticPrefix: true, ... }`
3. 引擎可根据策略调整上下文组装逻辑（当前已存储提示，未来可扩展）
