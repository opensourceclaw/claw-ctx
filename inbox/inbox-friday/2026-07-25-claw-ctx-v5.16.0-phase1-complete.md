### 1. ModelProfile 接口实现 ✅

**文件**: `src/model-profile.ts`

```typescript
export type OptimizationStrategy = 'static-prefix' | 'dynamic-load' | 'hybrid';

export interface ModelProfile {
  id: string;           // 模型标识
  name: string;         // 显示名称
  provider: string;     // 供应商
  
  cache: {
    staticPrefixBonus: boolean;  // 静态前缀是否提升缓存
    supported: boolean;          // 是否支持缓存
  };
  
  context: {
    maxTokens: number;           // 最大上下文窗口
    effectiveWindowRatio: number; // 有效窗口比例
    prefersSummary: boolean;      // 是否偏好摘要
  };
  
  optimization: {
    strategy: OptimizationStrategy;
    preloadPriority: string[];
    compressionThreshold: number;
  };
}
```

### 3. ModelProfileRegistry 类 ✅

提供以下方法:
- `get(id)` - 按 ID 获取配置
- `has(id)` - 检查配置是否存在
- `register(profile)` - 注册自定义配置
- `getAllIds()` - 获取所有配置 ID
- `getByProvider(provider)` - 按供应商筛选
- `getByStrategy(strategy)` - 按策略筛选
- `resolve(modelIdOrName)` - 解析模型 ID/名称/别名
- `getDefault()` - 获取默认配置 (hybrid 策略)
