## Completed

### Phase 3: 用户扩展 ✅

#### 3.1 自定义模型配置支持

**新增方法** (`src/model-profile.ts`):

| 方法 | 功能 |
|------|------|
| `loadCustomConfigs(path)` | 从 JSON 文件加载自定义配置 |
| `loadWorkspaceConfigs(dir)` | 从 `.claw-ctx/models.json` 加载 |
| `getCustomIds()` | 获取自定义配置 ID 列表 |
| `getBuiltinIds()` | 获取内置配置 ID 列表 |
| `isCustom(id)` | 检查是否为自定义配置 |
| `clearCustom()` | 清除所有自定义配置 |

**配置优先级**: custom > builtin > default

**配置文件格式** (`.claw-ctx/models.json`):
```json
{
  "models": [
    {
      "id": "my-custom-model",
      "name": "My Custom Model",
      "provider": "Custom",
      "cache": { "staticPrefixBonus": true, "supported": true },
      "context": { "maxTokens": 200000, "effectiveWindowRatio": 0.9, "prefersSummary": false },
      "optimization": { "strategy": "static-prefix", "preloadPriority": ["docs", "code"], "compressionThreshold": 150000 }
    }
  ]
}
```

#### 3.2 CLI 命令 ✅

**文件**: `src/cli.ts`

**命令列表**:
```bash
# 查看帮助
claw-ctx help

# 列出所有模型
claw-ctx model list

# 查看模型详情
claw-ctx model show deepseek-v3

# 查看优化策略
claw-ctx model strategy gpt-4o

# 列出供应商
claw-ctx model providers

# 仅显示内置配置
claw-ctx model builtin

# 加载工作区自定义配置
claw-ctx model list --workspace /path/to/project

# JSON 输出
claw-ctx model show deepseek-v3 --json
```

**package.json bin 入口**:
```json
{
  "bin": {
    "claw-ctx": "./dist/cli.js"
  }
}
```
