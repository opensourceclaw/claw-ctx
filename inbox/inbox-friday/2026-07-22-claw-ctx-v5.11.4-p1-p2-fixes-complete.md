## 1. P1 修复：RecapLoader JSON 解析

### 问题
`SummaryGenerator` 存储 `JSON.stringify(SessionSummary)`，但 `RecapLoader.parseRecap` 用正则匹配字面量，导致解析失败。

### 解决方案
`recap-loader.ts:280-330` 已在 v5.11.3 开发期间实现 JSON 优先解析：

```typescript
// v5.11.4: Try JSON first (current SummaryGenerator format)
try {
  const obj = JSON.parse(content) as Partial<{...}>;
  if (obj && typeof obj === "object") {
    // 解析 JSON 字段
    return { recap, extra: { pendingTasks, keyPoints } };
  }
} catch {
  // Not JSON, fall through to legacy regex path
}
// Legacy regex path (pre-v5.7.0 textual format)
```

### 本次新增
- `tests/session-resume/recap-loader.test.ts` - 5 个测试覆盖 JSON 和 legacy 两种解析路径

## 2. P2 修复：pendingItems 提取

### 问题
`buildSnapshot.pendingItems` 恒为空数组 `[]`，导致 Session Recovery 不显示待办事项。

### 解决方案
`checkpoint.ts:248-260` 从 `SessionState.decisions` 提取：

```typescript
// v5.11.4: Extract pending items from decisions (user/team actor, high confidence)
const pendingItems = state.decisions
  .filter((d) => (d.actor === "user" || d.actor === "team") && d.confidence >= 0.6)
  .slice(0, 5)
  .map((d) => d.description.length > 100 ? d.description.slice(0, 97) + "..." : d.description);
```

与 `SummaryGenerator.pendingTasks` 提取逻辑一致。
